# Support

Use the repository's Issues tab for setup questions, documentation problems, reproducible bugs, and feature requests.

Before opening an issue, read [Getting started](docs/getting-started.md), [Host integration](docs/integration.md), and the [FAQ](docs/faq.md).

Include your skill version, host version, operating system, entry points, and the exact stage that failed: import, identity linking, local persistence, upload, or remote retrieval. Use synthetic content and redact identifiers.

For security-sensitive reports, use [SECURITY.md](SECURITY.md). Maintainers will not ask you to paste an API key, password, or session token into an issue.

Useful integration examples and reproducible reports help other users get started and help maintainers focus on practical improvements.
