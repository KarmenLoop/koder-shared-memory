# Code of Conduct

Help keep this project welcoming, practical, and respectful.

- Critique ideas and behavior without attacking the person behind them.
- Give people room to ask questions, learn, and correct mistakes.
- Respect different backgrounds, identities, and levels of experience.
- Keep private information private. Ask before sharing someone else's messages or account details.
- Avoid harassment, threats, discrimination, and unwanted personal contact.

Maintainers may remove harmful content, close disruptive discussions, or restrict participation. They should explain moderation decisions when doing so does not expose private information or create further harm.

For a concern, ask a maintainer for a private contact method without posting identifying details about the people involved. If a private reporting channel is available, use it. Do not post a harassment report or sensitive evidence in a public issue.
