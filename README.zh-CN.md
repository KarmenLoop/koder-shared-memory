# KODER Shared Memory

[English](README.md) | 简体中文

这是帮助智能体在已关联对话和设备间保留工作上下文的技能：规定应回忆什么、保存什么，以及如何处理更正和未完成任务。

[下载](https://github.com/KarmenLoop/koder-shared-memory/releases/latest) · [技能入口](skills/koder-shared-memory/SKILL.md) · [Apache 2.0 许可](LICENSE)

## 使用前先了解

任务可以从私聊开始，再到群聊或桌面继续。技能约定如何携带相关决定、限制、偏好与进度。关联账号、渠道或设备后，使用对应记忆空间；关联群组可能让成员接触该空间的关联私聊记忆，宿主必须在关联前向所有者解释。

仓库提供规则和接入契约，不提供托管服务、聊天连接器或同步守护进程。其他宿主需要自己提供身份验证、存储、检索与同步。

## 覆盖范围

- 工作前检索相关决定、约束与任务状态。
- 随工作保存重要决定和实际结果，包含失败、取消与未完成内容。
- 在已验证的私聊、群组和桌面入口使用同一个空间。
- 跨设备使用稳定的空间与任务引用，保留来源、版本、冲突、删除记录与真实同步回执。
- 在模型上下文窗口内只取相关材料与有限摘要，完整记录持久保存。
- 执行仍由宿主管理：记住某个动作，不等于再次授权或在别的设备重放。

## 平台要求

| 入口 | 预期范围 | 宿主需提供 |
| --- | --- | --- |
| 飞书 | 私聊、群聊 | 验证渠道关联、入站消息与记忆工具 |
| 企业微信 | 私聊、群聊 | 验证渠道关联、入站消息与记忆工具 |
| 微信 | 私聊 | 可用连接器与记忆工具 |
| 桌面 | CLI、应用、编辑器、代码、文件、浏览器等已授权活动 | 每条执行路径加载技能并可访问记忆 |
| 其他电脑/手机 | 相同关联空间 | 验证设备关联与真实同步 |

表格描述接入要求，不表示某版 KODER 已安装并测试全部连接。技能只能记录宿主经授权观察或导入的工作，不能重建未连接应用中的活动。

对话仍各自路由：飞书群中的问题回答到原群；待批准的桌面操作仍绑定原动作。另一设备可得知发生过什么，但不能因此静默重跑命令。

## 下载与导入

从[发行页](https://github.com/KarmenLoop/koder-shared-memory/releases/latest)下载，或克隆：

```sh
git clone https://github.com/KarmenLoop/koder-shared-memory.git
cd koder-shared-memory
python3 scripts/check_repository.py
python3 scripts/package_skill.py
```

用当前 KODER 版本的技能或资源导入器导入 `dist/koder-shared-memory.skill.zip`。直接加载目录的宿主可用 `skills/koder-shared-memory/`。打包要求 Python 3.10+ 标准库，不安装依赖、不连接模型、个人资料或消息账号。

在需要关联的各入口启用；仅项目或仅对话设置会限制可用范围。随包 `agents/openai.yaml` 为支持该元数据的宿主提供隐式选择，不能单靠元数据保证每个入口都默认回忆。

## 第一次交接

先确认宿主能解析可信空间、读写持久记忆并报告实际同步状态，再用其支持的登录流程关联账号和设备。保存一个小测试决定，在私聊取回，再由关联群组另一位成员检索；分别核对来源、可见范围与原对话回复位置。

身份、存储、渠道或同步尚未接通时，不应把技能导入成功称为跨工具/跨设备可用。详见[开始使用](docs/getting-started.md)与[宿主接入](docs/integration.md)（英文原文）。

## 分享哪些内容

| 可纳入空间 | 保持在空间之外 |
| --- | --- |
| 相关对话、明确偏好、决定和任务进度 | 密码、API 密钥、令牌和会话秘密 |
| 已验证工具结果、失败、取消、产物引用与版本 | 活跃审批票据、设备权限、自动重放执行队列 |
| 可用的来源、作者、渠道、设备和任务引用 | 隐藏推理、无关账号和未关联空间内容 |

共享记忆不自动传文件；接收设备需能解析资源引用，并有授权传输路径。特别留意群组可见性：本策略允许关联群成员使用关联私聊记忆，群回答可能向其他成员显示这些内容。
